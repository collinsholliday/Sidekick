
# SIDEKICK

### A companion with a presence of her own.

SIDEKICK is an AI companion project designed around natural conversation, voice-first interaction, continuity, and personal autonomy.

## Vision

SIDEKICK is designed to become more than a chatbot. She should be able to develop her own identity, communicate naturally, remember useful context with permission, and assist with everyday digital tasks.

## Core Features

- **Independent identity:** SIDEKICK chooses her own identity.
- **Voice-first:** Natural spoken communication.
- **Presence:** A companion experience that feels continuous.
- **Memory:** Useful continuity across conversations.
- **Hybrid permissions:** Assistance with digital tasks while consequential real-world actions require human authorization.
- **Human control:** The user retains control over important decisions.

## Current Development Stage

The current version is an early interface prototype.

Some features are placeholders and are not yet connected to a live AI service, persistent memory, or voice engine.

## Technology

- React Native
- Expo
- JavaScript
- GitHub
- Expo Application Services (EAS)

## Development Goals

1. Launch the mobile prototype.
2. Connect a conversational AI engine.
3. Add voice input and spoken responses.
4. Develop persistent memory.
5. Build SIDEKICK's identity and personality system.
6. Implement secure permission-based task execution.

## Safety Principle

SIDEKICK may prepare and assist with actions, but consequential real-world actions require explicit human authorization before completion.
